What this console does

This is the staff-facing half of the charity events website. It provides full C.R.U.D. control over the core event data:

  • List — every event in the database, regardless of status, with the details needed for administration.
  • New — a validated form that inserts a charity event.
  • Update — select an event, load its details and its associated registrations, then save the changes.
  • Delete — remove an event, with clear feedback when the deletion is blocked because registrations exist.
  • Navigation — the sidebar menu is present on every page.

Authentication is not required for this assessment, as stated in the brief. In a production deployment the console would sit behind the university's single sign-on and the API would verify a role claim on every write request.

Technology

  • Angular v22 — standalone components, signals, resource(), zoneless change detection, built-in @if / @for control flow
  • Reactive Forms — typed forms with the same validation rules the API enforces
  • TypeScript — one shared data contract with the API's JSON
  • SCSS — the same design system as the public site, with an indigo admin accent
  • Node.js + Express.js + MySQL — the REST API it drives
  • Open-Meteo — geocoding for the venue coordinates
