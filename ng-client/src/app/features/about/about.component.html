The client-side website

This website is the client-facing half of the charity events case study. It lets the public browse charity events, search and filter them, read the full details of an event, see every ticket that has been purchased for it, and register for tickets.

Every page is rendered from live data: nothing on this site is hard-coded. The page sends an HTTP request to the Express REST API, the API queries MySQL and returns JSON, and Angular renders that JSON with its signal-based templates.

Technology stack

  • Angular v22 - standalone components, signals, resource(), zoneless change detection, built-in control flow
  • TypeScript - strict typing shared with the API's JSON contract
  • SCSS - custom design tokens, responsive layout
  • Node.js + Express.js - the REST API
  • MySQL 8 - events, categories, organisations and registrations
  • Open-Meteo API - the optional external weather integration
  • SCU cPanel - public deployment of both websites and the API
